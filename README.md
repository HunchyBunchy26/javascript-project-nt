## LITTLE FOOT Children's Clothing JavaScript Website

LITTLE FOOT is a front-end children's clothing shopping catalogue developed using HTML, CSS and JavaScript. The project showcases a selection of children's clothing through a clean, modern and user-friendly website.

The website allows visitors to browse products, select available colours and sizes, add items to a shopping cart and manage their selections. It also includes a Contact Us page with a form that provides client-side input validation and feedback.


## Project Concept and Theme

LITTLE FOOT is designed as a welcoming online children's clothing boutique, combining comfort, simplicity and thoughtful design. Its visual style uses a soft, neutral colour palette, clean layouts and clear typography to create a calm and approachable shopping experience.


## Project Objectives

The main objectives of the project were to:

* Develop a responsive, user-friendly children's clothing catalogue
* Create a clear website structure with accessible navigation between pages and sections
* Use HTML and CSS to build and style the website
* Apply JavaScript to introduce interactive features and dynamic content
* Implement a functional shopping cart with product selection, quantity management and automatic subtotal calculation
* Create a Contact Us form with client-side validation and user feedback
* Demonstrate practical understanding of front-end web development techniques


## Website Structure and Navigation

The website consists of two main pages:

* Home Page (home.html) – The main page introduces the LITTLE FOOT brand and displays the children's clothing catalogue. It includes a navigation bar, hero section, product catalogue, About section and shopping cart

* Contact Page (contact.html) – Provides a dedicated Contact Us section containing a form where visitors can enter their name, email address, subject and message

The navigation bar provides links to the Home, Products, About and Contact Us sections. Visitors can also navigate between pages using the links provided. The Products and About links on the Contact page direct visitors back to the corresponding sections of the Home page.

On smaller screens, the navigation links are presented through a collapsible hamburger menu to make the website easier to use on mobile devices.

## Key Features

The main features of LITTLE FOOT include:

* Dynamic Product Catalogue: Product cards are generated using JavaScript from an array of product objects, displaying product images, names, prices and available options.

* Product Selection: Visitors can choose from the available colours and sizes for each product before adding it to their shopping cart.

* Interactive Shopping Cart: Products can be added to the cart, with matching selections grouped together and quantities updated.

* Quantity Management: Visitors can increase or decrease product quantities and remove items from their cart.

* Automatic Subtotal Calculation: The shopping cart updates the subtotal whenever quantities or cart contents change.

* Cart Notifications: Visitors receive feedback when interacting with the shopping cart, including when attempting to open an empty cart.

* The Continue to Checkout button is included as a placeholder for a potential future checkout process.

* Mobile Navigation: A collapsible hamburger menu provides navigation on smaller screens.

* Contact Form Validation: The Contact Us form checks required fields and email format, providing appropriate feedback without reloading the page.

The project demonstrates front-end functionality only. The contact form does not send messages to a server, and the shopping cart does not process real payments.


## Technical Specifications

The LITTLE FOOT website was developed using the following technologies:

* HTML5 – Used to create the structure and content of the website, including pages, navigation, product sections and forms.

* CSS3 – Used to style the website, create layouts, apply the visual theme and provide responsive behaviour for different screen sizes.

* JavaScript – Used to implement interactive functionality, dynamically display products, manage the shopping cart, calculate subtotals and validate the Contact Us form.

Development Tools:

* Visual Studio Code – Used for writing and editing the project code.

* Google Chrome – Used to view, test and debug the website through the browser's Developer Tools.
